This page describes how the tool behaves in Color and Edit modes, including keyboard controls, cursor navigation, and reset actions.

Modes Overview

Color Mode

  • The palette displays colors.
  • Characters cannot be inserted, deleted, or structurally modified.
  • Keyboard navigation is enabled for selection only.

Edit Mode

  • The palette displays Braille characters.
  • Characters and line structure can be edited.
  • Keyboard input is restricted to specific editing keys.

Keyboard Navigation (Both Modes)

Keyboard navigation behaves the same in both Color and Edit modes. Navigation only changes the current selection and never moves, reorders, inserts, or deletes characters.

  • Arrow Left / Arrow Right — move selection horizontally
  • Arrow Up / Arrow Down — move selection vertically based on layout
The underlying text content never changes when using arrow keys. Only the selection cursor moves.

Edit Mode: Keyboard Editing Behavior

Spacebar (Insert Braille “0”)

  • Pressing Space inserts a Braille “0” character.
  • The character is inserted to the left of the cursor.
  • All existing text is pushed to the right.
  • The cursor advances one position to the right and ends up after the inserted character.
  • Space never replaces an existing character.

Backspace (Delete)

  • Deletes the character immediately to the left of the cursor.
  • The cursor moves left after deletion.
  • Deletion behaves like a normal notepad:
    • If at the start of a line, the line merges with the previous line.
    • Deletion continues seamlessly across line boundaries.

Enter (Line Break)

  • Pressing Enter inserts a line break.
  • The current line is split at the cursor.
  • Text to the right of the cursor moves to the new line.
  • The cursor moves to the beginning of the new line.
Edit mode follows standard text‑editor (notepad‑style) semantics, with the only exception being Space inserting a Braille “0” character.

Color Mode: Keyboard Behavior

Spacebar (Apply Color)

  • Pressing Space applies the currently selected color.
  • The color is applied to the currently selected character(s).
  • No text insertion, deletion, or structural change occurs.

Reset Actions

Reset Colors

  • Resets colors only.
  • Text content, characters, and line structure are not affected.
  • This behavior is correct and unchanged.

Reset Edits

  • Resets only Edit‑mode changes.
  • Reverts:
    • Character insertions
    • Character deletions
    • Line breaks
  • Colors are preserved exactly as they are.
  • Reset Edits does not affect Reset Colors.

Summary

  • Arrow keys always navigate selection only.
  • Edit mode enables text editing with restricted keys.
  • Color mode enables coloring without changing text.
  • Reset actions are fully separated between color and text.
