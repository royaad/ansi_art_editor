# ASCII/ANSI Art Editor

*Vibe‑coded* to the core, this project is a labor of love for ASCII and ANSI art. It brings a personal, aesthetically‑pleasing touch to your command‑line interface, turning ordinary terminals into vibrant canvases.

## Why this exists

- **Passion for ASCII/ANSI art** – born from countless hours crafting text‑based masterpieces.
- **Personal CLI experience** – makes your terminal feel more alive and uniquely yours.
- **Aesthetic pleasure** – smooth gradients, rich colors, and a sleek, glass‑like UI.

## What It Is

A lightweight, **web‑based** ASCII/ANSI art editor that runs entirely in the browser. It provides a canvas where you can edit, color, and preview text‑based art using modern CSS and JavaScript, with live rendering of ANSI escape codes. No installation required—just open the page and start creating.

While it supports ASCII and ANSI characters, the core focus is on **Braille art**, which offers a higher‑resolution, more expressive way to create CLI graphics.

## Launching the Editor

```bash
# Clone the repository (if you haven't already)
git clone https://github.com/yourusername/ascii_art_editor.git
cd ascii_art_editor

# Install dependencies (if any)
npm install   # or pip install -r requirements.txt

# Run the editor
npm run dev   # or python main.py
```
